# 📘 Smart Study Planner - PEP Class Assignment

A beginner-friendly **Smart Study Planner Web Application** built using **HTML, CSS, and Vanilla JavaScript**.  
This project helps students organize subjects, manage study plans, and improve productivity using simple logic and browser **LocalStorage**.


Preview Link: https://priyanshudotgit.github.io/studyPlanner-PEP/
---

## 🎯 Project Objective

The objective of this project is to build a Smart Study Planner that allows students to:

- Organize their study subjects
- Set subject priorities
- Track study progress
- Maintain data persistence using LocalStorage
- Improve daily study productivity

---

## 📌 Project Overview

The Smart Study Planner is a web-based application where users can:

- Add, view, and delete subjects
- Assign priority levels to subjects
- View an overview dashboard
- Store all data locally in the browser
- Retain data even after page refresh or browser restart

The project is designed using **simple JavaScript logic** and does **not use any frameworks**.

---

## 🧩 Application Sections

### 1. Dashboard
- Displays total number of subjects
- Gives a quick overview of study data

### 2. Subject Management
- Add new subjects
- Assign priority (High / Medium / Low)
- Delete existing subjects

### 3. Settings
- Reset all stored data
- Clear LocalStorage safely

---

## 💾 LocalStorage Implementation

This project uses **Browser LocalStorage** to store:
- Subject names
- Priority levels

All data remains available:
- After page refresh
- After browser restart

---

## 🛠️ Technical Requirements

- **HTML5** – Structure
- **CSS3** – Styling & Responsive Design
- **Vanilla JavaScript** – Application Logic
- **LocalStorage** – Data Persistence
- **No frameworks or libraries used**


---

## ▶️ How to Run the Project

1. Download or clone the project files
2. Open `index.html` in any modern browser
3. Start adding subjects and managing your study plan

No server or setup required.
